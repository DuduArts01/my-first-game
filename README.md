## 💡 Sobre o Projeto

Este projeto é um estudo prático de integração entre uma engine de jogos em JavaScript/Canvas (Kaplay) e uma interface de usuário moderna construída em React. 

Como parte do meu processo de aprendizado, **todo o código original do tutorial (que estava em JavaScript puro) foi totalmente refatorado e convertido para TypeScript**.

## 📚 Documentações Utilizadas

Durante o desenvolvimento e adaptação para TypeScript, as seguintes documentações oficiais foram consultadas:

1. **[Kaplay](https://kaplayjs.com)**: Biblioteca para criação de jogos em HTML5 Canvas.
2. **[Jotai](https://jotai.org)**: Gerenciamento de estado global minimalista para React (utilizado como ponte de comunicação entre o jogo e a UI).
3. **[React](https://react.dev)**: Biblioteca para construção de interfaces de usuário.
4. **[Framer Motion](https://motion.dev)**: Biblioteca de animações fluidas para componentes React.

## 🚀 Como Executar o Projeto

1. Clone o repositório:
  ```bash
  git clone https://github.com/DuduArts01/my-first-game.git
  ```

2. Instale as dependências:
  ```bash
  npm install
  ```

  ```bash
  npm i jotai
  ```

  ```bash
  npm i kaplay
  ```

  ```bash
  npm i framer-motion
  ```

  3. Inicie o servidor de desenvolvimento:
    ```bash
    npm run dev
    ```
